# CyR Seguridad — Sitio web comercial (V14)

Proyecto de sitio web responsive para **CyR Seguridad**, negocio de equipos de protección personal (EPP) y suministros industriales en Perú.

## Vista general

- Página de inicio con presentación del negocio.
- Catálogo visual de categorías de EPP.
- Navegación con desplazamiento suave y menú adaptable a móviles.
- Interacciones en JavaScript, incluyendo navegación y accesos para solicitar cotizaciones.
- Botones de contacto mediante WhatsApp y correo electrónico.
- Diseño adaptable a escritorio y celular.

## Tecnologías

**HTML5, CSS3 y JavaScript (vanilla)**. No requiere Node.js ni dependencias para ejecutarse localmente. Utiliza Google Fonts para tipografía.

## Cómo ejecutarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador, o utiliza **Live Server** en Visual Studio Code.
3. Para personalizar los contactos, revisa el objeto `CONFIG` en `script.js`.

## Estructura

```text
index.html      # Estructura de la página
styles.css      # Diseño responsive y animaciones
script.js       # Interacciones y catálogo
assets/         # Recursos visuales
LEEME.txt       # Notas originales de la versión
```

## Nota sobre el catálogo

El contenido y algunas imágenes son **demostrativos o ilustrativos**; la disponibilidad, características y certificaciones de los productos deben confirmarse con el negocio antes de usarlos como información comercial.

## Contexto del proyecto

Sitio creado como proyecto práctico para un negocio familiar, con iteraciones de diseño y mejoras de experiencia de usuario. Se presenta como **trabajo de portafolio**, no como prueba de experiencia laboral profesional previa.

## Privacidad

El sitio contiene datos de contacto comercial del negocio en `script.js`. No agregues credenciales, contraseñas ni datos de clientes al repositorio público.
